# 書籍管理システム セットアップ手順

## 前提条件

- **Node.js** v18 以上がインストールされていること
- **npm** がインストールされていること

## インストール手順

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. サーバの起動

```bash
npm start
```

サーバが起動すると以下のメッセージが表示されます：

```
書籍管理システム サーバ起動: http://localhost:3000
```

### 3. ブラウザでアクセス

ブラウザで以下のURLにアクセスしてください：

- **一覧画面**: http://localhost:3000
- **詳細画面**: 一覧画面の書籍タイトルリンクをクリック（別タブで開きます）

### 4. ポート番号の変更（任意）

デフォルトポート（3000）を変更したい場合は、環境変数 `PORT` を設定してください：

```bash
PORT=8080 npm start
```

## 使用パッケージ（OSS）

| パッケージ | バージョン | ライセンス | 用途 |
|:--|:--|:--|:--|
| express | ^5.2.1 | MIT | Webサーバフレームワーク |
| better-sqlite3 | ^12.9.0 | MIT | SQLite3データベースアクセス |
| axios | ^1.15.2 | MIT | HTTP クライアント（Google Books API呼び出し） |
| Vue.js | 3.x (CDN) | MIT | フロントエンドフレームワーク |

## 注意事項

- データベースファイル（`data/booklist.sqlite3`）は読み取り専用で使用しています
- Google Books API は1日1,000回までの呼び出し上限があります
- 書籍のサムネイル画像が取得できない場合は「NO IMAGE」画像が表示されます
